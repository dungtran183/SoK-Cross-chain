# BridgeShield: Enhancing Security for Cross-chain Bridge Applications via Heterogeneous Graph Mining

## One-Line Summary
Cross-chain bridges enable asset and state transfers across heterogeneous blockchains, but their complex cross-domain interactions introduce new attack surfaces that are difficult to monitor using traditional single-chain analysis methods.
